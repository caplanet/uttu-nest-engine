# 분리 작업을 기다리지 않는 독립 탐색 실험 결과

2026-09-09 / `C:\Caplanet\AiWorks\AdaptiveAlgorithm2`

**이번 독립 실행형 시제품은 현재 방식의 대체안으로 채택하지 않는 것이 적절하다.** 먼저 끝난 탐색이 다른 탐색을 기다리지 않고 계속 진행하는 구조는 동작했지만, 같은 시간의 최종 원단 길이는 6쌍 중 5쌍에서 기존 방식이 더 좋았다. 특히 여성 WSjk에서 악화가 일관됐다.

이는 모든 비동기 구조가 불리하다는 증명이 아니다. 이번에는 기존 탐색 코드를 재사용한 독립 Explore 스트림을 시험했다. 다음 작업을 받을 때 다른 스트림의 우수 배치를 받아서 시작하는 공유 작업 큐까지 구현한 결과는 아니다.

## 1. 무엇을 실제로 실행했는가

기존 방식은 하나의 Explore가 Separator 워커 3개를 사용한다. 각 분리 반복에서 모든 워커 완료를 기다린 뒤 가중 비용이 가장 좋은 배치를 다음 반복의 출발점으로 공유한다.

시험 방식은 3개의 독립 Explore 스트림이 각각 분리 워커 1개를 사용한다. 각 스트림은 자기 분리·폭 축소·Swap/R&R·다음 후보 탐색을 다른 스트림의 완료와 관계없이 계속한다. 인증된 개선 결과는 채널로 조정자에게 전달하고, 조정자는 도착 즉시 더 좋은 결과를 보존한다. 다른 스트림의 성공으로 진행 중인 분리 작업을 취소하지 않는다.

사용자 Config나 운영 코드를 변경한 것이 아니라 **별도 예제 실행기 안에서 같은 총 3개의 분리 워커를 두 실행 구조에 배분**했다. 샘플 수를 줄이거나 Swap/R&R/원본 검증을 꺼서 차이를 만들지 않았다.

시험 방식에서는 조각 하나의 이동 성공을 전체 분리 성공으로 취급하지 않는다. 기존 Explore의 `ExplFeas` 인증 경로를 그대로 사용했다. 종료 후 각 스트림의 최선 배치와 전체 최선 배치를 native 검증 및 새 OriginalOverlapGuard로 다시 검사했다.

## 5. 실제로 기다리는 구간은 얼마나 있었는가

별도 분리 라운드 진단기로 `move_items_multi`의 핵심 동작인 **동일 배치 load → 워커별 move_items → 전체 완료 → 승자 선택 → GLS 갱신**을 재현했다. 초기 배치를 1% 줄여 충돌을 만든 뒤 입력별 80개 라운드를 측정했다.

| 입력 | 80라운드 벽시계 시간 | 모든 워커 시간 슬롯 합계 중 먼저 끝난 워커의 완료 간격 |
|---|---:|---:|
| WSjk | 1.031s | 약 **8.30%** |
| OPS2 | 0.468s | 약 **15.26%** |

계산은 `Σ(라운드 종료 시각 − 각 워커 완료 표시 시각) / (라운드 시간 합계 × 워커 수)`다. 완료 표시 뒤 일부 진단 비용과 집계 비용도 포함되므로 순수 OS idle 시간의 직접 측정값은 아니다. 이 진단기에는 전체 Explore 수명주기, Separator Swap hook, 원본 인증이 포함되지 않는다. 따라서 위 값을 전체 Explore의 대기 비율이나 예상 속도 향상률로 해석하면 안 된다.

확인한 사실은 **대기할 여지가 존재한다는 것**이다. 다만 이 대기를 없애는 과정에서 탐색 배치 공유 방식도 달라지므로, 이 비율만으로 더 좋은 수율을 얻는다고 판단할 수 없다.

## 6. 왜 기대만큼 좋아지지 않았는가

코드 구조와 관측 결과를 함께 보면, 기존 방식의 ‘각 반복에서 좋은 배치를 공유하는 효과’를 잃는 영향이 원인 후보다. 독립 스트림은 각자 다른 경로로 빠르게 진행할 수 있지만, 다른 스트림의 유망한 배치를 다음 탐색의 출발점으로 쓰지 않는다.

다만 이번 실험은 대기만 제거한 동등성 실험이 아니다. 독립화와 함께 RNG 진행, GLS 이력, 폭 축소 시점, ALNS 학습 이력과 배치 공유 방식이 달라졌다. 어느 한 요인이 몇 mm를 악화시켰는지 분리해서 입증하지는 않았다.

**요청한 방향을 더 평가한다면, 진행 중인 느린 작업은 유지하면서 작업을 끝낸 스트림이 그 시점의 유망한 공통 배치나 별도 교란 후보를 받는 방식이 다음 대상이다.** 성공 결과를 모으기만 하는 현재 시제품과 구분해야 한다. 이번 결과를 보고 그 후속 구조도 반드시 실패한다고 단정하지 않는다.
