# Draft Init 진행 기록 — 2026-09-07

## 완료한 구현

좌하단부터 위로 열을 채우고 다음 열로 이동하는 선택형 Column Draft Init과 WPF 연결을 구현했다. 비교 JSON에는 최종 좌표만 있으므로 실제 선택 순서·부착 이력이 알려진 것은 아니다. Order 진단 후 루트 폭의 고정 제한, 부착 후보 범위와 위치 선택을 수정했다. NFP 후보는 공차를 반영한 실제 충돌 검사와 원본 윤곽의 원단 경계 검사로 채택한다.

추가 대화 자료를 참고해 mm 기준 누적 최대 경계 이탈을 제한하는 보수적 단순화를 구현했다. 명시한 간격/겹침 오프셋 직후의 윤곽을 기준으로 원본 간선 이력과 연속 선분 거리 인증을 사용한다. mm 모드는 면적 비율 단순화와 좁은 홈 닫기를 대체하고 Draft의 추가 면적 단순화도 생략한다. 원본 재단 윤곽과 허용 겹침은 별도로 유지한다.

WPF의 `최대 이탈(mm)` 입력 기본값은 0.5mm, 체크박스는 기본 꺼짐이다. Draft와 독립적인 전역 import 옵션이며 새 배치를 비교할 때는 `Use Hints`를 끈다.

현재 소스 스냅샷에는 앞서 작업한 Jagua 0.8.1 API 대응, 충돌 평가/SIMD 변경, 힌트 분석·복구와 관련 진단 테스트도 포함된다. 이들 변경의 배경은 `HANDOFF_SESSION.md`에 있다.

모두 156개 배치 및 원본 윤곽 경계 검사를 통과했다. 독립 GEOS 검사에서는 설정 공차와 조각별 0.002mm 수치 여유를 초과하는 겹침이 없었다(교차 면적 임계값 1e-5mm²). 독립 단순화 검사 1248개 결과의 포함 관계와 경계 거리를 확인했다. 수치 오차 허용은 0.0002mm이며 실제 구현의 채택 기준은 샘플 검사가 아닌 연속 경계 인증이다.

관련 Rust/C# 테스트와 Release 네이티브·WPF 빌드를 통과했다. 기존 WPF 경고 14개가 남아 있고, 네이티브 DLL과 WPF 출력 폴더 DLL의 SHA-256 일치를 확인했다. 상세 수치·검증 항목은 [측정 기록](MM_MEASUREMENTS_2026-09-07.md)에 보존한다. 원시 JSON과 독립 검사 스크립트는 로컬 `output/draft-column/`의 생성 산출물로 커밋하지 않는다.

참고 배치의 78.79%는 아직 재현하지 못했다. 시간과 밀도는 설정에 따라 달라지며 10초 미만을 보장하지 않는다. 일부 NFP Boolean 결과에서 퇴화/자기 교차 경로의 위상 복원 실패가 남아 있다. 실패 후보를 제외하고 충돌 검사를 유지한다. 이번 작업에서 Boolean 커널 자체는 변경하지 않았다.

## LP 압축 논의 — 미구현 후속안

사용자는 Draft 뒤에 LP 압축을 추가하면 밀도가 더 오를지 질문했다. 답변은 개선 가능성에 대한 제안이며 **Draft Init 직후 LP 단계는 아직 구현하거나 측정하지 않았다.** 기존 `swarm-core/src/optimizer/polish/lp.rs`에는 조각별 평행이동과 사용 길이를 변수로 하는 LP 압축이 있으며 일반 후처리 경로에서 사용된다.

후속 구현 방향:

1. Draft 직후 선택형 LP 단계에서 여러 조각을 함께 이동해 사용 길이를 줄인다.
2. 충돌, 허용 겹침 및 원본 윤곽의 원단 경계를 검증한다. 검증 실패나 길이 악화 시 기존 배치를 유지한다. 기존 LP의 충돌 검사만으로 Draft의 원본 경계 계약까지 자동 충족한다고 가정하지 않는다.
3. LP가 정체되면 앞쪽 빈 공간에 작은 조각을 재삽입하고 다시 압축하는 방식을 비교한다.
4. 동일 Draft 결과에서 압축 전후 길이·밀도·추가 시간·채택 반복 수를 측정한다. Init과 압축 시간을 분리해 기록한다.

LP는 현재 접촉 관계 근처에서 공동 이동을 찾는 데 유리하지만 조각 순서나 부착 관계를 크게 바꾸는 탐색을 대체하지 않는다. 현재 68.0555%에서 참고 78.79%까지 가려면 동일 면적/고정 폭에서 사용 길이가 약 13.6% 줄어야 한다. 이는 필요한 개선량의 계산이며 LP 예상 성능이나 달성 보장이 아니다.
