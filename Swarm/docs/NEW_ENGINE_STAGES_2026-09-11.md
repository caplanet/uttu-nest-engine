## 2. 지시서가 스스로 모순되는 곳과 선택

| 항목 | 모순 | 구현 |
|---|---|---|

| 2행 계수 (제10차) | A = x_B + y_A, B = y_B + x_A — 좌표 합이 계수로 들어가 차원이 맞지 않는다 | 스위치(`--spec-row2`) |
| 3·4행, 조건부 5행 | 계수·상한 유도가 서로 다르고 보조열 의미가 없다 | 스위치(`--spec-rows34`, `--spec-fifth`) |

`sound` 행: 현재 상대 위치가 모서리의 비금지 쪽(d ≥ 0)이면 `n·Δrel ≤ d` 한 행. 한 축 패스에서는 경계를
정수 상대 이동으로 내린다 — 조각별 절사(§5.7 함정 5)가 분수 경계를 1격자 넘어 정수 NFP 판정에 겹침으로
잡히는 것을 막는다.

코드 검토(읽기 전용 워크플로, 발견 12건 중 10건 확인)에서 나온 수정을 반영한 뒤 다시 재도 0이다:
- 볼록 꼭짓점 접촉에서 두 모서리 행이 교집합을 요구해 옆 미끄러짐까지 막던 과잉 구속 → 막는 방향으로 한 격자
  움직였을 때 NFP 안일 때만 행을 건다.
- 지시서 판이 뒷면 모서리에도 행을 걸어 Spec25 는 LP 불능, AsmM1 은 쌍 고정 → 모든 판에서 뒷면 모서리 제외.
- 부분 되돌림 → 지시서대로 패스 전체 롤백 + 스텝 반감(부분 되돌림은 `--partial-repair` 측정용).
- 최종 상태 0x200 고정·채택 안 된 단계의 점수 이력, 명령행 검증, 최종 검증 몫 500ms 예약, 워커 panic 을
  시간 초과로 보고하던 문제.

재측정 (시험 46개 통과): 축 분해 / 2D / 기계어판 / STEP 15mm 모두 폭 7142.45mm 그대로.

원인은 Draft 의 구조다. 점수가 같으면 x 오름차순으로 고르므로 모든 조각이 놓일 때 왼쪽의 무언가에 닿은 채
놓인다. 그래서 오른쪽 끝 조각에서 왼쪽 벽까지 접촉이 끊기지 않고 이어지고, x 패스(목적 = 폭)로는 움직일 수
없다. 사슬을 끊으려면 y 로 비켜 틈을 여는 이동이 필요한데, 지시서의 y 패스는 목적이 0 이라 그런 이동에 보상이
없다.

## 4. Swarm warm start

`scripts/full_bench/make_warm.py` 로 마커와 새 초기배치를 jagua-rs `ExtSPOutput`(인스턴스 + `"solution"`,
`run_time_sec` 추가)으로 합치면 FullBench 가 그대로 받고 Swarm 은 자체 LBF 를 건너뛴다.

**정정 — 원단 경계에 딱 붙인 배치는 Swarm 이 버린다.** Swarm 은 가져온 배치의 원단 포함을 자기 충돌 형상
(겹침 허용치 절반만큼 줄이고, 외곽을 부풀리는 단순화를 거친 도형)의 bbox 로 허용오차 1e−4mm 안에서 검사한다
(`src/ffi_step.rs:1627-1643`, `swarm-core/src/structure/pipeline.rs:1470`). 원본이 벽에 닿은 새 엔진 배치는
단순화된 형상이 벽 밖으로 튀어나와 "seeded item 7 lies outside the fixed strip bounds" 로 **156개 전부 버려지고**,
Swarm 은 자기 초기배치(LBF)를 처음부터 다시 만든다. 처음의 짧은 확인(초기 71.438%)과 첫 20시드 시험이 모두
